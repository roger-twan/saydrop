# Saydrop Asset Guide

## App icons

| File | Format | Use |
|---|---|---|
| [High resolution app icon](icons/Saydrop-app-icon.png) | 1920 × 1920, RGBA | Large displays, design work, and derived assets |
| [Standard app icon](icons/Saydrop-app-icon-1024.png) | 1024 × 1024, RGBA | Regular displays and app icon source |
| [macOS ICNS icon](icons/Saydrop.icns) | macOS `.icns` | Native app icon |

The full-color app icon is different from the monochrome menu bar status icon. The client source assets are also kept in `apps/macos/SaydropApp/Resources/`.
